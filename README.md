# DJ-41 PRO II

A modern scientific calculator inspired by the Casio fx-82AU PLUS II, redesigned as a premium desktop and web application.

## About

The DJ-41 PRO II was created and developed by **Dheera Jayachitra** under **DPE Studios**.

Inspired by the functionality, layout and educational value of the Casio fx-82AU PLUS II, the DJ-41 PRO II reimagines the traditional scientific calculator with a modern interface, enhanced usability and digital accessibility.

The goal of this project is to preserve the familiar calculator experience used by students while introducing a refined design language and additional software capabilities.

## Features

* Scientific calculations
* Trigonometric functions
* Inverse trigonometric functions
* Hyperbolic functions
* Factorials
* Powers and roots
* Fraction and decimal conversion
* Memory functions
* Degree, Radian and Gradian modes
* Engineering notation
* Calculation history
* Keyboard support
* Touch support
* Installable web application
